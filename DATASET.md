# Datasets

This profile repository does not ship training or evaluation datasets.

Featured systems keep their own public or local data:

- **Grounded Document Parser** — synthetic and public regression fixtures in [`grounded-docparse`](https://github.com/pypi-ahmad/grounded-docparse/tree/native-document-ingestion)
- **LoRA Fine-tune Studio** — user-provided local datasets
- Other featured projects — see each repository

Internal outcome numbers in [`docs/sanitized-outcomes.md`](docs/sanitized-outcomes.md) come from employer evaluations. Those source files are not published.

Tracked analysis directories (`.codegraph/`, `.firecrawl/`, `.ua/`, `graphify-out/`) are local indexes, search caches, and graph exports. They are not datasets.
